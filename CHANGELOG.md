# Изменения

## 1.51 — язык интерфейса

- Английский и русский интерфейс с автоматическим выбором из языков macOS.
- Английский как запасной вариант для неподдерживаемых языков.
- Перевод кнопок, подсказок, уведомлений и основных сообщений об ошибках.
- Язык показывается в настройках; исходные диагностические данные сохраняются.
- Английская инструкция первого запуска внутри DMG.

## 1.50 — первый выпуск в этом публичном репозитории

- DXMT Async как основной метод для совместимых DX11 x64 игр.
- GameHub: включение для выбранной игры и обычный запуск через лаунчер.
- CrossOver: постоянная настройка бутылки для запуска из CrossOver/Steam.
- Подключение других совместимых Wine-сред и выбор лаунчера.
- Библиотека игр, обложки, диагностика и восстановление настроек.
- Python runtime внутри приложения и проверка переносимости.
- Дополнительный GPTK-прогрев для существующих предусмотренных сценариев.

Экспериментальный DX12 Async не включён. Контролируемый численный выигрыш текущей сборки пока не установлен.
