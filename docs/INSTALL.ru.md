# Установка и восстановление

## Первый запуск

1. Скачайте `DeadlockWarmer.dmg` из Releases этого репозитория.
2. Откройте образ и перенесите **Shader Warmer** в **Applications**.
3. Приложение не прошло notarization Apple. Если macOS блокирует скачанную копию, откройте Терминал и выполните команду для установленного приложения:

   ```sh
   xattr -dr com.apple.quarantine "/Applications/Shader Warmer.app"
   ```

4. Откройте Shader Warmer снова. Отключать Gatekeeper целиком не требуется.

Для готовой сборки не нужны Homebrew, Python или Xcode. Для DXMT Async нужны Apple Silicon, macOS 15+ и Rosetta 2.

## GameHub

1. Установите игру. Выберите в GameHub **Wine Proton 11 x64** и **DXMT v0.80**.
2. Один раз запустите игру, чтобы создать контейнер, затем закройте её.
3. Найдите игру в Shader Warmer. В параметрах выберите **DXMT Async**, в обзоре — **Включить фикс**.
4. Если программа просит подтвердить DX11, проверьте, что игра действительно его поддерживает. Выберите DX11 в игре, если он не выставляется автоматически.
5. Запускайте игру через GameHub обычным способом.

GameHub использует общий компонент DXMT. Флаги включаются для выбранного контейнера; для нескольких управляемых игр нужны отдельные контейнеры. Общий компонент восстанавливается после отключения последней игры.

## CrossOver

1. Установите игру в CrossOver и убедитесь, что она запускается. Выберите DirectX 11 в игре.
2. Закройте Windows-приложения в бутылке. Выберите игру и нужную бутылку в Shader Warmer; при необходимости используйте **Сменить лаунчер**.
3. Включите Async и дождитесь проверки совместимости.
4. Запускайте игру из CrossOver или Steam. Shader Warmer можно закрыть.

Настройка действует на **всю бутылку**, а не только одну игру. Изменение графического backend в CrossOver может отключить интеграцию. При обновлении Wine/CrossOver может потребоваться отключение и повторная подготовка среды.

## Другие Wine-среды

Подключите существующий prefix с `user.reg` и `drive_c`, укажите совместимый Wine runtime. После подготовки запускайте Windows x64 `.exe` через Shader Warmer. Подключение не переносит игру между бутылками и не обходит требования Steam или другого игрового клиента.

## Если что-то не работает

- Проверьте API игры: DX12-only и 32-битные игры не подходят.
- Убедитесь, что выбраны нужные установка игры, бутылка и runtime.
- Если изменился Wine или компонент DXMT, отключите интеграцию и подготовьте среду заново.
- При запаздывающих объектах отключите Async и проверьте тот же эпизод. Приложите описание к issue.
- В диагностике можно собрать локальный архив. Просмотрите его перед публикацией: в нём могут быть имена пользователя и локальные пути.

## Отключение и удаление

Используйте действие отключения на странице игры. В GameHub восстанавливаются управляемые настройки выбранной игры; общий DXMT возвращается после отключения последней игры. В CrossOver отключение восстанавливает настройки бутылки.

Бэкапы и частные runtime находятся в `~/Library/Application Support/ShaderWarmer/`. Сначала отключите Async во всех управляемых средах и только затем удаляйте приложение и эту папку. На другой Mac переносите DMG или приложение, а не резервные копии старой системы.
