# Совместимость

Основной метод: DXMT Async для Windows **x64 / DirectX 11** на Apple Silicon, macOS 15+, Rosetta 2.

| Сценарий | Состояние |
| --- | --- |
| GameHub, Wine Proton 11 x64, DXMT v0.80 | Автоматическое включение и восстановление; обычный запуск через GameHub. |
| CrossOver с совместимым Wine runtime | Автообнаружение бутылок, проверка среды, обычный запуск после активации; действие на всю бутылку. |
| Другие совместимые Wine-среды | Ручное подключение prefix/runtime, проверка и запуск через Shader Warmer. Не заявляется поддержка любого лаунчера. |
| Deadlock DX11 | Есть положительная ручная обратная связь о плавности. Контролируемый количественный эффект текущей сборки не установлен. |
| Другие DX11 x64 игры | Требуется совместимость с DXMT; работоспособность и картинка проверяются отдельно. |
| DX12-only / Windows x86 (32-bit) / Intel Mac | Не поддерживаются этим Async методом. |
| GPTK-прогрев | Отдельный дополнительный workflow; не равнозначен DX12 Async. |

Проверка создания устройства D3D11 подтверждает базовую совместимость runtime, но не прохождение игры и не отсутствие графических ошибок. Наличие игры в библиотеке тоже не означает подтверждённую совместимость.

Async может временно пропускать отрисовки, пока компилируется пайплайн. Это может уменьшить блокировку кадра, но также задержать появление объекта или эффекта. Полное устранение фризов, рост среднего FPS и отсутствие артефактов для всех игр не обещаются.

Для воспроизводимого отчёта укажите версию игры, API, macOS/чип, Wine/CrossOver/GameHub, настройки, состояние кэшей и один и тот же эпизод. Разделяйте первый и повторный проход. Для численных заявлений используйте [протокол](../benchmarks/PROTOCOL.md).
