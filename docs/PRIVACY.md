# Данные и сеть

Shader Warmer читает локальные установки игр, Wine prefix, настройки лаунчеров и доступные кэши для показа библиотеки и выбора среды.

Настройки, резервные копии и записи восстановления сохраняются на этом Mac. Бэкапы и частные runtime находятся в `~/Library/Application Support/ShaderWarmer/`. Сохраняйте эту папку до отключения Async.

Обложки сначала ищутся в локальном Steam-кэше. При включённой загрузке обложек приложение может обратиться к публичному CDN Steam, передав Steam App ID в URL. Загрузка включена по умолчанию и отключается в настройках. CDN получает обычные сетевые метаданные запроса, включая IP-адрес.

Автоматической отправки диагностических архивов разработчику нет. Архив создаётся по запросу пользователя и может содержать локальные пути, имя пользователя и сведения об окружении. Перед прикреплением к публичному issue просмотрите его и удалите личные сведения.

Игры и лаунчеры имеют собственное сетевое поведение. При сборке из исходников также может скачиваться зафиксированная версия Python; это относится к сборке, а не к активации DXMT Async у получателя готового приложения.
