# Изменения и отчёты

Цель проекта — уменьшать задержки компиляции шейдеров во время игры на Mac. Основное публичное направление — DXMT Async для совместимых DX11 x64 игр.

В bug report укажите чип Mac, macOS, версию приложения, игру, API, лаунчер/runtime и шаги воспроизведения. Для графических проблем полезен один и тот же эпизод с Async и без него. Удаляйте личные пути из диагностических архивов перед публикацией.

Изменения должны сохранять восстановление исходных настроек, проверку компонентов и работу без путей разработчика. Не добавляйте пользовательские prefix, кэши, игровые записи и локальные бэкапы.

Для изменений компиляции, рендера и кэшей применяйте [benchmarks/PROTOCOL.md](benchmarks/PROTOCOL.md). Субъективная плавность не подтверждает процент ускорения. У Async учитывайте пропущенные отрисовки и запаздывание объектов.

Перед PR выполните тесты из [BUILD.md](docs/BUILD.md), а при изменении упаковки — проверку переносимости. Сторонние лицензии и уведомления должны сохраняться.
